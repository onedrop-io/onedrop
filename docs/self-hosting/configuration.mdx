OneDrop is a Laravel application, so the usual Laravel settings (`APP_URL`, `DB_*`, `QUEUE_CONNECTION`, and so on) apply. This page covers the settings specific to OneDrop. They live in `config/sandbox.php` and are set in `.env`.

## Sandboxes

| Variable                                                                                                         | Default                            | Description                                                                                                                                                                                                                                                                                                                                    |
| ---------------------------------------------------------------------------------------------------------------- | ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SANDBOX_PROVIDER`                                                                                               | `docker`                           | Where project sandboxes run: `docker` locally; in production, `blaxel` for [Blaxel](/self-hosting/sandboxes#run-sandboxes-on-blaxel) or `runtime` for [Runtime Cloud](/self-hosting/sandboxes#run-sandboxes-on-runtime-cloud).                                                                                                                 |
| `SANDBOX_DOCKER_IMAGE`                                                                                           | `onedrop-sandbox:latest`               | Image built by `php artisan sandbox:build-image`.                                                                                                                                                                                                                                                                                              |
| `SANDBOX_DOCKER_MEMORY`                                                                                          | `2g`                               | Memory limit per sandbox container.                                                                                                                                                                                                                                                                                                            |
| `SANDBOX_DOCKER_CPUS`                                                                                            | `2`                                | CPU limit per sandbox container.                                                                                                                                                                                                                                                                                                               |
| `SANDBOX_DOCKER_IDLE_SECONDS`                                                                                    | `60`                               | Seconds a Docker sandbox may sit unused before it's [suspended](/self-hosting/sandboxes#idle-sandboxes-are-suspended) (memory kept, woken by its next use). `0` never suspends.                                                                                                                                                                |
| `SANDBOX_DOCKER_STOP_AFTER_MINUTES`                                                                              | `5`                                | Minutes a suspended Docker sandbox stays paused before it's stopped, freeing its memory (it starts again on its next use, files kept). `0` never stops.                                                                                                                                                                                        |
| `SANDBOX_DOCKER_HOST`                                                                                            | `127.0.0.1`                        | Host the browser uses to reach published container ports.                                                                                                                                                                                                                                                                                      |
| `SANDBOX_DOCKER_REACH`                                                                                           | `published`                        | How the app reaches sandbox ports: `published` (the ports Docker publishes on `SANDBOX_DOCKER_HOST`), or `network` (container name and port on `SANDBOX_DOCKER_NETWORK`). The [server install](/install#install-on-a-server) uses `network`, so nothing but the gateway can reach sandboxes.                                                   |
| `SETUP_TOKEN`                                                                                                    | (none)                             | When set, the first account can only be created from `/register?setup=<token>`. The [server install](/install#install-on-a-server) sets it and prints the link.                                                                                                                                                                                |
| `SANDBOX_DOCKER_NETWORK`                                                                                         | (none)                             | Docker network sandboxes join. The [one-container install](/install) uses `drop`, so sandboxes reach the app at `http://drop:8000`.                                                                                                                                                                                                            |
| `SANDBOX_DOCKER_STORAGE_PATH`                                                                                    | `storage/app/sandboxes`            | Host folder for App Storage buckets and Claude sign-ins. Each project's buckets are in `<path>/project-<id>/storage`, mounted into its sandbox. Each user's Claude Code sign-in is in `<path>/user-<id>/claude`, mounted into all of their sandboxes, so they sign in once. Only Claude Code reads it. Empty keeps both inside each container. |
| `SANDBOX_PORT`                                                                                                   | `8000`                             | Port the app's dev server listens on inside the sandbox.                                                                                                                                                                                                                                                                                       |
| `SANDBOX_PROXY_PORT`                                                                                             | `8081`                             | Port of the host-rewriting proxy in front of the app, used by the preview and published URLs.                                                                                                                                                                                                                                                  |
| `SANDBOX_SHELL_PORT`                                                                                             | `7681`                             | Port of the web terminal behind the Shell tab.                                                                                                                                                                                                                                                                                                 |
| `SANDBOX_SSH_PORT`                                                                                               | `2222`                             | Port of the SSH server behind Tools → Developer → SSH.                                                                                                                                                                                                                                                                                         |
| `SANDBOX_GATEWAY_SECRET`                                                                                         | empty                              | Shared secret for the Cloudflare Worker that serves previews on Laravel Cloud. See [Previews on Laravel Cloud](/self-hosting/cloudflare-preview-gateway).                                                                                                                                                                                      |
| `SANDBOX_CALLBACK_URL`                                                                                           | `http://host.docker.internal:8000` | How code inside a sandbox reaches OneDrop to report agent events. In production, your public `APP_URL`.                                                                                                                                                                                                                                        |
| `SANDBOX_BACKUP_DISK`                                                                                            | default disk                       | Filesystem disk that holds each project's code backup. Unset, it's the app's default disk (`FILESYSTEM_DISK`). See [Code backups](/self-hosting/sandboxes#code-backups).                                                                                                                                                                                                                               |
| `SANDBOX_TASK_COPIES`                                                                                            | `true`                             | Give each task its own copy of the project's sandbox, with its own preview; its work is merged back when applied. Off, tasks share the main sandbox. See [Tasks and the board](/guides/tasks).                                                                                                                                                 |
| `SANDBOX_MAX_TASK_COPIES`                                                                                        | `3`                                | Most task copies one project runs at once. Each copy is a full sandbox.                                                                                                                                                                                                                                                                        |
| `SANDBOX_GIT_ALLOW_PRIVATE_REMOTES`                                                                              | `false`                            | Let Tools → Git push to remotes on private networks, e.g. a self-hosted Forgejo on your LAN. Off, remotes must be public HTTPS hosts.                                                                                                                                                                                                          |
| `GITHUB_APP_ID`, `GITHUB_APP_SLUG`, `GITHUB_APP_CLIENT_ID`, `GITHUB_APP_CLIENT_SECRET`, `GITHUB_APP_PRIVATE_KEY` | empty                              | The GitHub App behind **Connect GitHub** in Tools → Git. See [GitHub App](/self-hosting/github-app).                                                                                                                                                                                                                                           |
| `BL_API_KEY`                                                                                                     | empty                              | Blaxel API key, from the Blaxel console. Keep it in your secret manager.                                                                                                                                                                                                                                                                       |
| `BL_WORKSPACE`                                                                                                   | empty                              | Your Blaxel workspace name.                                                                                                                                                                                                                                                                                                                    |
| `BLAXEL_IMAGE`                                                                                                   | `onedrop-sandbox`                      | Blaxel image pushed by `php artisan sandbox:build-image`.                                                                                                                                                                                                                                                                                      |
| `BLAXEL_MEMORY_MIB`                                                                                              | `4096`                             | Memory per Blaxel sandbox; also sets CPUs (one per 2048 MB). New accounts allow 4096 at most.                                                                                                                                                                                                                                                  |
| `BLAXEL_REGION`                                                                                                  | empty                              | Region for new sandboxes, such as `us-pdx-1`. Empty picks the closest one.                                                                                                                                                                                                                                                                     |
| `BLAXEL_CLI`                                                                                                     | `bl`                               | Path to the Blaxel CLI, used to push the image.                                                                                                                                                                                                                                                                                                |
| `RUNTIME_API_KEY`                                                                                                | empty                              | Runtime Cloud API key, from [API keys](https://withruntime.com/account/keys). Keep it in your secret manager.                                                                                                                                                                                                                                  |
| `RUNTIME_IMAGE`                                                                                                  | `onedrop-sandbox:latest`               | Runtime image built by `php artisan sandbox:build-image`.                                                                                                                                                                                                                                                                                      |
| `RUNTIME_FUNDING`                                                                                                | `trial`                            | `trial` uses the free hours only. Set `paid` once the account has credit.                                                                                                                                                                                                                                                                      |
| `RUNTIME_VCPU`, `RUNTIME_MEMORY_MIB`, `RUNTIME_DISK_MIB`                                                         | `2`, `4096`, `8192`                | Size of each Runtime sandbox. The trial allows 2 vCPUs and 4096 MiB at most.                                                                                                                                                                                                                                                                   |
| `RUNTIME_TIMEOUT_SECONDS`                                                                                        | `3600`                             | Lease length, at most an hour. When it ends the sandbox pauses with its memory kept, and the next request wakes it.                                                                                                                                                                                                                            |
| `RUNTIME_PERSISTENT`                                                                                             | `false`                            | Paid only. Renews the lease while credit lasts, so a long agent run is never paused partway through.                                                                                                                                                                                                                                           |
| `RUNTIME_PREVIEW_VISIBILITY`                                                                                     | `private`                          | `private` links carry a token but only open in their own tab. `public` (paid only) shows previews inside the workspace.                                                                                                                                                                                                                        |

## Agent

| Variable                   | Default                                | Description                                                                                                                            |
| -------------------------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `SANDBOX_AGENT`            | `HarnessRunner`                        | Class that starts agent runs; `HarnessRunner` runs each project's chosen agent (OpenCode, Claude Code or Codex). Tests use `FakeAgentRunner`. |
| `SANDBOX_MODEL_CLAUDE`     | `anthropic/claude-sonnet-5`            | Model used for Anthropic connections.                                                                                                  |
| `SANDBOX_MODEL_CODEX`      | `openai/gpt-5.6`                       | Model used for OpenAI connections.                                                                                                     |
| `SANDBOX_MODEL_OPENROUTER` | `openrouter/anthropic/claude-sonnet-5` | Model used for OpenRouter connections.                                                                                                 |
| `SANDBOX_MODEL_GEMINI`     | `google/gemini-3.8-flash`              | Model used for Gemini connections.                                                                                                     |
| `SANDBOX_MODEL_OLLAMA`     | `ollama-cloud/glm-5.3`                 | Model used for Ollama Cloud connections (a user's own server starts on its first model).                                               |
| `SANDBOX_OLLAMA_PRIVATE_SERVERS` | `true` when `APP_ENV=local` | Let users connect an Ollama server on a private or loopback address. Off on servers, so the platform can't be made to call internal addresses. |

These are the defaults for new projects; users can pick any other model in the chat. Models use OpenCode's `provider/model` format.

| Setting                     | Description                                                                                                              |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `SANDBOX_MODEL_CATALOG_URL` | Where the model list comes from. Defaults to `https://models.dev/api.json`, the catalog OpenCode uses. Cached for a day. |
| `SANDBOX_CHATGPT_MODELS_URL` | Where ChatGPT lists the models a ChatGPT sign-in's plan includes with Codex. Defaults to `https://chatgpt.com/backend-api/codex/models`. Cached for an hour per connection. |
| `sandbox.featured_models`   | Models shown first in the picker, per provider, in `config/sandbox.php`.                                                 |

## Publishing

| Variable            | Default                      | Description                                                                                                                                              |
| ------------------- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SANDBOX_PUBLISHER` | `tailscale`                  | How projects get their own URL. Tests use `fake`.                                                                                                        |
| `TAILSCALE_AUTHKEY` | empty                        | Optional. With a key, devices join unattended. Without one, the Publish panel shows a sign-in link. See [Tailscale publishing](/self-hosting/tailscale). |
| `TAILSCALE_IMAGE`   | `tailscale/tailscale:stable` | Image for the per-project Tailscale container.                                                                                                           |

## Accounts

| Variable            | Default | Description                                                                                   |
| ------------------- | ------- | --------------------------------------------------------------------------------------------- |
| `AUTH_VERIFY_EMAIL` | `true` (`false` when `APP_ENV=local`) | Require new accounts to verify their email. Set to `false` on servers without outgoing email. |

Make a user an admin with `php artisan onedrop:admin you@example.com`.

To let people log in with Google, Microsoft, GitHub, GitLab, or single sign-on, see [Social login](/self-hosting/social-login).

## Link previews

Links to your install show a preview card in Slack, Facebook, X, and other apps. The tags live in `resources/views/app.blade.php` and point to `public/images/og.png`. The image URL is built from the request, so serve the app over HTTPS behind a trusted proxy (the server install's Caddy setup already does this).

To change the image, edit `resources/og/og-image.html` and re-render it:

```bash
node resources/og/render.mjs
```

Slack and Facebook cache previews. After changing the image, re-scrape with the [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) or wait for the cache to expire.
