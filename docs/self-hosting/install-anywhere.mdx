<Tip>
    The quickest way onto a server is the [one-command
    install](/install#install-on-a-server): it works on any Linux server with
    Docker, including Amazon Linux, and runs everything in one container. This
    page covers the non-container install.
</Tip>

`infra/server/bootstrap.sh` installs OneDrop on a fresh Ubuntu 24.04 server, x86_64 or Arm. It works on any provider (Hetzner, DigitalOcean, Google Cloud, a machine in your office) and is what the [AWS setup](/self-hosting/deploy-aws) runs on first boot.

## Requirements

- Ubuntu 24.04 with root access
- Ports 80 and 443 open to the internet
- A domain name pointing at the server, including a wildcard record (`*.onedrop.example.com`) for previews and shells. Or use `<ip>.sslip.io`, which needs no DNS.
- At least 4 GB of RAM; 8 GB or more for several people building at once

## Install

<Steps>
  <Step title="Make a release tarball">
    From a checkout of the repository:

    ```bash
    git ls-files -co --exclude-standard -z | tar --null -czf onedrop.tar.gz -T -
    scp onedrop.tar.gz root@your-server:/tmp/
    ```

  </Step>
  <Step title="Run the install script">
    ```bash
    mkdir -p /tmp/onedrop && tar -xzf /tmp/onedrop.tar.gz -C /tmp/onedrop infra/server
    APP_DOMAIN=onedrop.example.com APP_RELEASE=/tmp/onedrop.tar.gz bash /tmp/onedrop/infra/server/bootstrap.sh
    ```
    `APP_RELEASE` can also be an `https://` or `s3://` URL.
  </Step>
  <Step title="Create your admin account">
    Open `https://onedrop.example.com` and sign up. The first account on a new install is the admin. To make someone else an admin later, run:

    ```bash
    sudo -u onedrop php /opt/onedrop/current/artisan onedrop:admin them@example.com
    ```

  </Step>
</Steps>

## What the script sets up

| Component                 | Details                                                                      |
| ------------------------- | ---------------------------------------------------------------------------- |
| Packages                  | PHP 8.4 (FPM), Composer, Node.js 22, Docker, Caddy, Tailscale                |
| `onedrop` user                | Owns the app and belongs to the `docker` group                               |
| PHP-FPM pool              | Runs as `onedrop` so the app can manage sandboxes                                |
| `onedrop-queue` service       | The queue worker that creates sandboxes and runs agents                      |
| Caddy                     | HTTPS for the app and for `preview-<id>` / `shell-<id>` addresses            |
| `/opt/onedrop/bin/deploy`     | Deploys a new release: `sudo /opt/onedrop/bin/deploy /path/to/onedrop.tar.gz`        |
| `/opt/onedrop/bin/set-domain` | Moves the server to a new domain: `sudo /opt/onedrop/bin/set-domain example.com` |

The first deploy writes `/opt/onedrop/shared/.env` with production settings: SQLite database, email verification off (no outgoing email is configured), and the sandbox gateway on your domain. Edit it and run a deploy to change settings.

The script is safe to run again; it skips steps that are already done.
