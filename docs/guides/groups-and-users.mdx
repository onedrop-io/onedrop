## Groups

Open **Groups** in [Settings](/guides/settings) to see the groups you belong to.

- Anyone can create a group and becomes its owner
- Owners can add existing users by email, change roles between owner and member, remove members, rename the group, and delete it
- Members can leave a group
- A group always keeps at least one owner

## Admins

Admins see **Users** under **Admin** in [Settings](/guides/settings). From there they can:

- See every user and how many groups they're in
- Grant or revoke admin access for other users (not themselves)

Admins can also see and manage every group, project, and invite.

The seeded dev user (`dev@example.com`) is an admin.
