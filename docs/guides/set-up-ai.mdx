---
title: 'Set up your AI'
description: 'Connect Anthropic, OpenAI, Google Gemini, or OpenRouter so the agent can build with your own account.'
---

The agent that builds your apps uses your own AI account: your ChatGPT Plus or Pro plan, or your own API key. You pay your provider directly, with no credits and no markup. You connect at least one provider after signing up, and you can change it later in **Settings → AI**.

## Providers

<Tabs>
  <Tab title="Claude (Anthropic)">
    Paste an Anthropic API key from [console.anthropic.com](https://console.anthropic.com/settings/keys). OneDrop checks the key with Anthropic before saving it.

    To build on your Claude Pro or Max plan instead, click **Use my Claude subscription instead**, then **Use my Claude subscription**. There's nothing to paste: you sign in to Claude from your project, in Claude Code's own sign-in.

    <Steps>
      <Step title="Open a project on Claude Code">
        A subscription only works with the [Claude Code agent](#choose-the-agent). Anthropic lets its own agent use a subscription, but not other agents like OpenCode.
      </Step>
      <Step title="Sign in to Claude">
        Above the chat box, click **Sign in to Claude**. The **Shell** tab opens and runs `claude auth login`.
      </Step>
      <Step title="Approve on Claude">
        Open the link it shows, sign in to Claude and approve. Copy the code Claude gives you and paste it into the Shell tab.
      </Step>
      <Step title="Start building">
        Back in the chat, the line above the chat box says who Claude Code is signed in as. Send your message.
      </Step>
    </Steps>

    <Note>
      OneDrop never sees or stores your Claude login: it stays inside Claude Code, in your sandboxes, as Anthropic requires. On OneDrop installs that use Docker sandboxes, one sign-in works in all of your projects. On other sandbox providers, sign in once in each project.
    </Note>

    If Claude turns down your sign-in, the chat tries your message once more by itself. If Claude Code isn't signed in, or your sign-in has really expired, the chat tells you to sign in again and **Sign in to Claude** comes back above the chat box. Once you've signed in, the chat picks your message back up by itself, so you don't need to send it again. Disconnecting Claude in **Settings → AI** signs Claude Code out of your sandboxes. Claude subscription tokens from `claude setup-token` can't be pasted.

  </Tab>
  <Tab title="OpenAI">
    Sign in with your ChatGPT account to use your ChatGPT Plus or Pro plan instead of paying for API usage:

    <Steps>
      <Step title="Start sign-in">
        On the Codex card, click **Sign in with ChatGPT**. OneDrop shows a one-time code.
      </Step>
      <Step title="Approve on OpenAI">
        Open [auth.openai.com/codex/device](https://auth.openai.com/codex/device), sign in to ChatGPT, and enter the code. The code expires after 15 minutes.
      </Step>
      <Step title="Wait for OneDrop">
        Keep the OneDrop tab open. It connects Codex as soon as you approve.
      </Step>
    </Steps>

    If OpenAI says to enable device code sign-in, turn it on in ChatGPT under **Settings → Security**, then click **Get a new code** in OneDrop. A code issued before you changed the setting keeps failing. On a ChatGPT Business or Enterprise workspace, an admin may need to allow device code sign-in first.

    Your Codex connection works with two agents: OpenCode (pick an OpenAI model) or OpenAI's own [Codex agent](#choose-the-agent).

    OneDrop keeps your ChatGPT sign-in and refreshes it for you. Sandboxes only get a short-lived access token, never the refresh token. If OpenAI ends the sign-in (for example, after you sign out of all devices), the chat asks you to sign in with ChatGPT again.

    <Note>
      On a ChatGPT plan, the agent can only use the models OpenAI includes with Codex (currently recent GPT models, such as `gpt-5.5`). The model picker only lists those, and projects start on the first one if the default OpenAI model isn't included.
    </Note>

    To pay per use instead, click **Paste an OpenAI API key instead** and paste a key from [platform.openai.com](https://platform.openai.com/api-keys). OneDrop checks it with OpenAI before saving it.

  </Tab>
  <Tab title="Gemini (Google)">
    Paste a Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey). OneDrop checks the key with Google before saving it. Usage is billed to your AI Studio account, which has a free tier.

    <Note>
      You can't connect a Gemini subscription (Google AI Pro or Ultra). Google's terms forbid other apps from using the Gemini CLI sign-in, and Google suspends accounts that do. Use an API key, or pick a Gemini model through OpenRouter.
    </Note>

  </Tab>
  <Tab title="OpenRouter">
    Click **Sign in with OpenRouter** and approve access. OpenRouter creates a key you control and can revoke. A small link lets you paste an existing OpenRouter key instead.
  </Tab>
</Tabs>

## Manage connections

In **Settings → AI** you can:

- See each connected provider, showing only the last four characters of its key (or of your ChatGPT account ID)
- Reconnect with a new key
- Choose which provider is the default when you have more than one
- Disconnect a provider

Keys are encrypted in the database, never sent back to your browser, and only passed to the agent inside your project sandboxes.

## Choose the agent

Each project runs one of three agents in its sandbox. The agent picker sits under the chat box, left of the model picker, in both the new-project prompt and the project chat.

| Agent           | Runs                                                                      | Best for                                          |
| --------------- | ------------------------------------------------------------------------- | ------------------------------------------------- |
| **OpenCode**    | Any connected provider except a Claude subscription                       | Choosing between providers and hundreds of models |
| **Claude Code** | Claude models only, with an Anthropic API key or your Claude subscription | Building on your Claude Pro or Max plan           |
| **Codex**       | OpenAI models only, with your ChatGPT sign-in or an OpenAI API key        | OpenAI's own agent, on your ChatGPT plan          |

- New projects start on whatever agent and model you picked last. Until you pick one, they start on your AI subscription: Claude Code for a Claude subscription, or OpenCode with Codex for a ChatGPT sign-in. Without a subscription, they start on OpenCode (or Claude Code, if that's the only agent your connections can run).
- Claude Code only shows up once you've connected Claude. While it's chosen, the model picker only lists Claude models.
- Codex only shows up once you've connected Codex. While it's chosen, the model picker only lists OpenAI models (on a ChatGPT plan, the ones OpenAI includes with Codex).
- Switching agents starts a fresh conversation: the new agent can't read the old one's history, but your app's files stay as they are. The chat notes the switch.
- You can't switch while the agent is working. Stop it or wait for it to finish first.

## Choose a model

Each project runs on the model you pick. The picker sits under the chat box, in both the new-project prompt and the project chat.

- **Providers:** the rail on the left shows the providers you've connected. The star tab shows your favorites.
- **Search:** type to filter by name. Featured models are listed first; every other model that can use tools is under **More models**. OpenRouter alone offers a few hundred.
- **Recent:** the models you picked last are listed first under each provider.
- **Favorites:** hover a model and click its star.
- **Reasoning:** the button next to the model sets how hard it thinks, from the levels that model supports (for example Low, Medium, High, Extra high, Max). **Default** uses the model's own default.

Changing the model takes effect on your next message; the agent keeps the conversation. Each model shows its context size and price per million tokens (input/output).

New projects start on the model you picked last. Until you pick one, they start on your subscription's (or else your default provider's) default model, set by whoever runs OneDrop (`SANDBOX_MODEL_*` in [Configuration](/self-hosting/configuration#agent)).

<Warning>
    OpenRouter reserves the maximum possible cost of each request before running
    it. If your OpenRouter balance is low, requests can be refused even though
    the final cost would be small. The chat tells you when this happens; add
    credits and try again.
</Warning>
