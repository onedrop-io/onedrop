OneDrop turns a description like "a time-off tracker for my team" into a working web app. An AI coding agent builds it as real, tested code inside an isolated sandbox, and the app runs live in a preview next to the chat while the agent works.

What sets it apart:

- **Built for production.** The agent writes standard code (React, or Laravel with a database when the app needs one), runs the tests, and has sign-in, secrets, analytics, and feature flags built in. It's code a developer can review and extend.
- **Bring your own subscription.** Build on your ChatGPT Plus or Pro plan, or your own key for Anthropic, OpenAI, or OpenRouter. You pay your provider directly, with no credits and no markup.
- **Deploy anywhere.** Run it on your laptop, any Ubuntu server, or AWS. Your apps and data stay on infrastructure you control, and nothing is locked to one host or one framework.
- **Free and open source.**

## How it works

<Steps>
    <Step title="Connect your AI">
        Add an API key or sign in with OpenRouter. See [Set up your
        AI](/guides/set-up-ai).
    </Step>
    <Step title="Describe your app">
        Type what you want to build. OneDrop creates a project and a sandbox for it.
        See [Build a project](/guides/build-a-project).
    </Step>
    <Step title="Watch it get built">
        The agent reads, writes, and runs code in the sandbox. You see each step
        in the chat and the app in the preview.
    </Step>
    <Step title="Share it">
        Publish the project to give it its own URL, private to your team or
        public. See [Publish a project](/guides/publish).
    </Step>
</Steps>

## Who it's for

OneDrop is built for trusted teams: people inside a company who want to build internal tools without setting up a development environment. It is not designed to host apps for anonymous strangers.
